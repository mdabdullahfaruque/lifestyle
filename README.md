# Lifestyle

A multi-category, multi-vendor e-commerce marketplace for Malaysia — vendors sell through a shared
marketplace while keeping their own branded storefront on a subdomain (with optional custom domain).

**Stack:** .NET 10 · EF Core 10 (code-first) · PostgreSQL 17+ · Angular 20+
